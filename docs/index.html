DeepSeek Harness · DSH Plugin

Working Changes

在会话顶部看到当前分支改了哪些文件，Hover 查看文件明细，点击在右侧栏打开 diff。 只读，不打断当前工作流。

GitHub 源码 下载发布版

在 DSH 中安装

打开「插件 → 发现 → 索引源」，添加下面的市场索引：

https://xuex991.github.io/dsh-working-changes/index.json

功能

  • 当前工作区相对 HEAD 的文件变更
  • 文件增删行数与状态
  • 原生右侧栏 unified diff
  • 只读，无 stage / commit / push
