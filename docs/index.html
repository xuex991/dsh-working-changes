Working Changes

在当前 Session 的一个或多个 Git 仓库中查看未提交改动，并从同一个下拉浏览 本地分支的 Git log。只读，不打断当前工作流。

在 DSH 中安装

打开「插件 → 发现 → 索引源」，添加下面的市场索引：

https://xuex991.github.io/dsh-working-changes/index.json

功能

  • 当前工作区相对 HEAD 的文件变更
  • 按项目浏览本地分支 Git log
  • 查看 Commit 相对父提交的文件与 diff，并自动打开第一个文件
  • 自动发现并列子仓库并分组展示
  • 可折叠、可搜索的变更文件树
  • 文件增删行数与状态
  • 只读，无 stage / commit / push
