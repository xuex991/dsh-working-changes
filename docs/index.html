PLUGIN 01 / UI

当前变更

读取版本…

在 DSH 会话里看清「我在哪个分支、改了什么、本 Session 提交了什么」。 支持一个工作区下多个子项目，按仓库分组显示分支、文件状态和 +/−， 并能从历史下拉查看本 Session 各本地分支的 Commit 与内容 diff。

只读 多子项目 Session 提交 Commit diff

命令行安装 / 更新

dsh plugin --profile desktop add -w 'github:xuex991/dsh-working-changes'
或在「插件 → 添加插件」输入仓库地址 查看源码 发布记录 需 DSH ≥ 0.2.1-rc.2
PLUGIN 02 / PROMPT

可读输出

读取版本…

为 DSH 增加始终生效的输出约定：先给结论，少堆术语，保持简洁， 不确定时明确说明，而不是假装知道。

System prompt Always on 无运行时依赖

命令行安装 / 更新

dsh plugin --profile desktop add -w 'github:xuex991/dsh-readable-output'
查看源码 需 DSH ≥ 0.1.0-rc.6

01 / UI 插件 固定市场索引

在 DSH「发现 → 索引源」保留本页地址。索引会指向当前插件版本，不需要换链接。

02 / 两个插件 重复安装命令

新机器或更新时，重新执行对应插件的 add 命令即可；两条命令都走同一个市场索引版本。
